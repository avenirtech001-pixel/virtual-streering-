Quick Start Guide

Install and Connect

  1. Download and run the Windows installer, or extract the portable ZIP to a folder of your choice.
  2. Install ViGEmBus separately from its official source if you need virtual Xbox controller emulation.
  3. Allow the receiver on your trusted network when prompted by Windows Firewall. Connect both your phone and PC to the same network.
  4. In your game settings, select the VSW virtual controller and bind your controls.
